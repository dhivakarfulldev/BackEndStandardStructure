# Node.js Backend – Users CRUD API

This project is a beginner-friendly **Node.js backend application** that provides a  API for managing users.

The application performs basic **CRUD operations**:

- Create a new user
- Get all users
- Get a user by ID
- Update user details
- Delete a user

## Technologies Used

- Node.js
- Express.js
- Postman

## User Fields

Each user contains:

- Name
- Email
- Password



## API Base URL 

  [https://backendstandardstructure.onrender.com/users]

## API Endpoints  

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/users` | Get all users |
| GET | `/users/:id` | Get user by ID |
| POST | `/users` | Create a new user |
| PUT | `/users/:id` | Update user details |
| DELETE | `/users/:id` | Delete a user |
